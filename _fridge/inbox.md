# Fridge inbox

Write freeform notes under "## Nieuw" — any language, one thought per line
(e.g. "gekocht: kip, rijst, sojasaus" or "op: uien en knoflook"). Edit this
file directly on github.com when you're away; next time you run the app at
home (`npm run dev`, with your local LLM up), open `/fridge` and hit
"Verwerken" to fold these into the fridge list. Processed notes move to
"## Verwerkt" below instead of being deleted, so nothing silently vanishes if
something gets missed — feel free to clear old entries there yourself.
